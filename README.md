## :memo: Description

C'est une application web complète basée sur l'architecture **Jakarta EE (J2EE)**. Elle permet de digitaliser le processus de prise de rendez-vous pour les patients et la gestion des actes médicaux pour les dentistes.

Le projet met en œuvre une architecture **MVC** stricte :
* **Modèle** : Entités JPA (Hibernate) mappées sur une base MySQL.
* **Contrôleur** : Servlets et EJBs (Enterprise JavaBeans) pour la logique métier.
* **Vue** : Pages JSP (JavaServer Pages) avec JSTL.
